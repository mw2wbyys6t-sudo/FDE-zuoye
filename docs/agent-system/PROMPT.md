## 6. 硬性约束（实现阶段必须逐条对照）

**代码规范**

1. 每个函数写中文 docstring，说明入参、出参、失败时的行为。
2. 关键业务逻辑（安全审查、权限校验、人工确认）必须写中文行内注释，说明"为什么这么卡"。
3. 配置统一放 `config.yaml`；密钥、模型地址不得硬编码，只允许 `${ENV}` 引用。
4. 所有对外接口统一返回：`{"ok": bool, "data": ..., "error": {"code": str, "msg": str}}`。

**交付要求（每阶段）**

1. 变更文件清单。
2. 启动与自测命令。
3. 一段能直接跑通的验证脚本。
4. 该阶段最可能出问题的地方。

**其它**

- 按 harness 工程开发：先契约、闸门、trace、评估，再挂 agent。
- 多 agent 体系；本地大模型推理；记忆框架可替换；知识库多维度。
